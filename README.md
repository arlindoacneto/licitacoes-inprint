# Central de Licitações Inprint

Portal de entrada para as duas versões de teste. Somente HTML, CSS, JavaScript e os endereços dos ambientes protegidos são publicados neste repositório.

O GitHub Pages hospeda este portal estático. As aplicações completas dependem do servidor Python, OCR Windows e processamento de análise no computador responsável. Os acessos seguem pelos túneis HTTPS protegidos por senha. O computador e a conexão devem permanecer ativos.

Nenhuma senha, documento corporativo, custo interno ou base de licitações integra este repositório. As cópias de testes são independentes das bases de trabalho. A atualização de `links.json` mantém os endereços de entrada `/v1/` e `/v2/` estáveis quando os túneis temporários mudam.
